# Vibe Check

A simple Expo app with one home screen.

## Run it on your phone with Expo Go

1. Install [Expo Go](https://expo.dev/go) on your phone (App Store / Play Store).
2. From this directory, install dependencies and start the dev server:

   ```
   cd vibe-check
   npm install
   npm start
   ```

3. Scan the QR code that appears in the terminal with your phone's camera (iOS) or the Expo Go app (Android).

Your phone and computer need to be on the same Wi-Fi network.
